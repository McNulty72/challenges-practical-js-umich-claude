Credit Risk Classifier

Solution for Challenge n1-02.

Challenge description

Given a score between 0 and 1000, classify it as follows:

  • Excellent: 800 or higher
  • Good: 650 to 799
  • Acceptable: 500 to 649
  • High Risk: below 500

If the score is not a number or is out of range, display "Invalid score".

Additionally the classifier receives a boolean variable hasDefaults, If is true the category changes to "High Risk" - unless it wast "Execellent", in which case it shifts to "Acceptable".

Test cases

  • Test at least these cases: -1, 0, 499, 500, 649, 650, 799, 800, 1000, 1001, "700"
  • Test each case with and without hasDefaults

Bonus challenge: turn it into a function that takes two arguments, score and the boolean hasDesfaults and returns the category.

JavaScript concepts included in this challenge

  • Booleans
  • Comparison operators
  • Logical operators
  • if/else if/else statements
