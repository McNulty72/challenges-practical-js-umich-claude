Solution for Challenge n1-04: Price series statistics

Challenge description

Starting from `const prices = [102.5, 99.8, 101.2, 105.6, 98.4, 103.9, 107.1]; compute the sum, mean, maximum, minimun, and the maximun`s position (index). Build a new array with daily variations for each price.

Don't use `Math.max`, `reduce` or other shorcuts, the target is to practice loops.

JavaScript concepts included in this challenge

  • While loops
  • For loops
  • Exit conditions
