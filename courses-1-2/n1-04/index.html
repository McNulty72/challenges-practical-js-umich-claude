Solution for Challenge n1-04: Price series statistics

Challenge description

Starting from const prices = [102.5, 99.8, 101.2, 105.6, 98.4, 103.9, 107.1]; calculate the sum, average, maximum, minimun, and the maximun`s position (index). Afterward, create a new array containing the daily vvariations: each price minus the price of the previous day.

Don't use Math.max, reduce or other shorcuts, the goal is to practice loops.

It is considered complete when...

  • It works with any non-empty array, including negative values.
  • The variations array has exactly one less element than the prices array.

JavaScript concepts included in this challenge

  • arrays
  • indexes
  • length
  • for...of loops
  • for loops
