Solution for Challenge n1-05: Reusable functions

Challenge description

Define the following functions:

  • calculateVAT(base, rate)
  • applyDiscount(price, percentage)
  • formatEuros(amount): returns a string like "1234.50 €"
  • average(numbers)
  • isEven(n)

Rewrite the challenge n1-01 using the above functions

Criteria for Completion:

  • No function uses console.log: they all return their result.
  • The console.log statements are placed outside, when calling the functions.
  • Each function has at least two test calls with the expected result in a comment.

JavaScript concepts included in this challenge

  • Define functions
  • Parameters and arguments
  • return
