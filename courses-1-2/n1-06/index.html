Solution for Challenge n1-06: Portfolio without mutations

Challenge description

A position is an object { ticker, quantity, averagePrice } and a portfolio is an array of positions. Write:

  • positionValue(pos, currentPrice)
  • buy(pos, quantity, price): returns a new position with the updated quantity and average price without modifying the original one
  • portfolioValue(portfolio, prices): where prices is an object like { AAPL: 190, MSFT: 410 }

Criteria for Completion:

  • Demonstrate with console.log that the original position does not change after buying.
  • portfolioValue works with any number of positions.

JavaScript concepts included in this challenge

  • Objects
  • Dot and bracket notations
  • Spread syntax
